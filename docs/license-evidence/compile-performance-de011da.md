The final receipt-bound candidates passed 160 Node and 160 Chromium corpus
compiles across XeLaTeX/LuaLaTeX and both years. Each group compares baseline
and candidate, with repeated documents in one worker. Comparisons cover PDFs,
errors, diagnostics, available SyncTeX, recorder inputs, auxiliary files, and
bibliography/index outputs. Node additionally compares geometry and dependency
telemetry. Fixed clocks exist only in test staging. Base-format hashes match;
fallback format generation is rejected. Known baseline defects remain explicit.
The baseline engine generations are those of `2025-2b3c48691f3cd6d7` and
`2026-8b7946970153c52e`, with original Xe/Lua generation receipts at `0dddc924`.

test-clock worker overlays are not generation receipts or shipping assets.

against both years, 16 compiles total. This CLI's pdfLaTeX result does not

License-tool tests, release-mode annual license checks, link inventory,

packed-SDK consumer passed strict TypeScript checking and runtime imports

## Clean Linux rebuild

The changed XeTeX/dvipdfmx and LuaHBTeX families were rebuilt for both years
on x86_64 Linux from the extracted archives. This is not a claim that the
unchanged families were freshly rebuilt again. Their exact artifact/receipt
pairs and prior source evidence are retained.

Docker used the digest-pinned Emscripten 3.1.46 base with
`docker build --no-cache --pull`. A recorded transport-only Dockerfile
adaptation copies archived TeX Live sources instead of fetching Git, and
preseeds SHA-512-verified port sources after clearing compiled port caches.
Runtime build containers use `--network none`. Native build parallelism is
limited to 16. The original archived engine build scripts and glue are used.
Native XeTeX geometry and visual-fixture SHA gates passed for both years;
the LuaHBTeX build's WTPDF/SHA-2 checks also passed.

## XeTeX link-order difference

For both years, the rebuilt JavaScript has exactly the same six `invoke_*`
function bodies and identical remaining code; only their ordering changes.
Link-map record multisets are identical after removing address, offset, and
size columns. The maps contain 16,731/17,054 data rows for 2025/2026;
2,645/6,993 sequence positions differ. No archive, member, or symbol record
is added or removed. This matches the previously investigated pinned-toolchain
[link-order behavior](corresponding-source-2025-3a630ec.md), but current
variants were also executed independently.

The rebuilt WASM SHA-256 values are
`a65c4e7aebd41735cb5eabcbcf0808ee6044668247e0c4509650c3210421d824`
(2025) and
`dd55c918ef157ebf99905b5f4e694c2b23a89abe21bd0bd1673446ea23b8a2aa`
(2026). Test staging asserts these actual rebuilt files replace the release
files before execution. Eighty Chromium corpus compiles, 40 per year,
matched the receipt-bound candidate in all compared observable results.
Eighty Node corpus compiles also matched, 40 per year. The first 2025
attempt had a stalled baseline font download, producing a baseline-only
missing-font diagnostic. Its failed log is retained; the unchanged rerun
passed in 213.87 seconds (2026 passed in 207.93 seconds).
The shipping files remain the original receipt-bound CI bytes.
